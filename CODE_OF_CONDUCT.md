# Community Code of Conduct

Project maintained by [arsamnet.com](https://arsamnet.com).

Be respectful and constructive in discussions and reviews. Treat others professionally regardless of background or experience. Provide actionable criticism of code and security designs, not personal attacks. Do not harass, threaten or disclose another person's private information. Report disruptive conduct privately to project maintainers where possible. Maintainers may remove comments, reject contributions or restrict participation to protect the community.
